关于作品

面向物联网 / 电子专业学生的交互式 ESP32 学习平台。把开发板装进浏览器——内置 Wokwi 在线模拟器、可交互接线图与实验室模拟台，零硬件、零后端、离线可用，从点亮一颗 LED 一路学到把 ESP32 接上 AI。

  • 13 模块 / 47 章节 · 约 10.6 小时渐进式学习路线

  • 实验室模拟台 · 24 种元件 + AI 语音控灯

DESIGN APPROACH

从问题到体验

让没有实体开发板的学习者，也能操作并理解 ESP32 实验。

独立开发的 Vue 3 交互式教学站，已上线知乎 AIWorks。课程与前端实现一同设计，连接知识、操作与自测。

将知识组织成学习路径

规划十三个模块、四十七个章节，循序展开课程内容，并设置自测与结业证书。

把实验带进浏览器

接入 Wokwi 模拟器与实验室，配合交互接线图，让学习者在零硬件条件下进行操作。
