DESIGN APPROACH

从问题到体验

在限时开发中，把设施异化与实验体遭遇组织成可游玩的科幻解谜。

武汉翌光计划 Game Jam 团队作品，使用 RPG Maker MV 制作可玩原型，已发布机核。我的职责为游戏策划与测试。

以环境推进叙事

玩法和关卡围绕异化设施与编号实验体展开，让探索中的环境变化承载故事。

在限时创作中保留测试

建立 Playtest 清单，记录并跟进体验缺陷，在 48 小时团队协作中推进可游玩版本交付。
