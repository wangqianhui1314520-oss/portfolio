- 原有可见帧统计补充 p95、最大帧间隔及超过 50 ms 的帧数，恢复页面时清空旧窗口。统计代表最近一段可见渲染窗口，可能跨越转场；不是浏览器全生命周期统计。
- 入口和沉浸式模块图缓存统一为 `cinematic-v21.13`；runtime-settings 的四个调用者使用同一 URL，避免设置状态出现两个模块实例。生成 36 个国际化文件。

## 未验收项目
