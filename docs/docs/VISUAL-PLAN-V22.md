日期：2026-10-19。前提是 [v21.19 的卡顿修复](QA-V21-19.md) 已完成，整站在集显上能稳定在 50–60 fps。

状态：已选定方向并实施第一部分，未提交、未发布。决定是**界面用 B 全息战术，旁白用透明玻璃**。已完成的内容见第 8 节。

证据都在 `.workbuddy/perf-v22/visual-v22/`（本地，不提交）：

- `visual-audit-v21.19.jpg`：问题标注板，20 个编号与下文第 1 节一一对应。
- `clean/`：同一轮浏览的截图，每个时刻各有一张带界面（`-ui`）和一张只保留 3D 画面（`-clean`）的版本。

## 0. 结论

**问题不在效果太少。** 让网站显得不够高级的，主要是下面三件事：

1. **几处明显的瑕疵拉低了整体质感**：
   - 行星表面像迷彩。
   - 小行星是黑色剪影。
   - 航行时会闪过一块品红方块。
   - 圆环压住文字，作品舱的正文是斜的。
2. **界面没有统一的语言。**
   - 金属框、玻璃板、圆环、方盒灯各是一套做法。
   - 光是 `.archive-glass-panel` 这一个选择器，就在 7 个样式表里有约 290 条规则；面板自身的背景在 6 个文件里写了 20 次，其中 14 次带 `!important`。
3. **最关键的四个瞬间没有被"导演"。** 启航、跃迁、锁定、停靠这四刻，镜头、光、声音和界面没有在同一条时间轴上联动。
   - 序章里已经写好的跃迁扭曲、色散和拖影，星域航行时没有用上。

**集显上已经没有 GPU 余量。** 所以顺序是：

1. 先修瑕疵、统一界面。这两步几乎不占 GPU。
2. 再按画质档位加入光学效果和跃迁效果。
3. 最后做材质和模型。

**界面方向建议：**

- 全站以"电影极简"为基础。
- 只在锁定星舰的那一刻借用"全息战术"。
- "光学玻璃"只留给场景里的 3D 面板。
- 三种方向的样张已经做好，请你选定。

## 2. "高级科幻感"的验收方式

1. **一个画面一个主体。** 每个状态都有明确的主体，其他元素的亮度不超过主体的一半。
2. **只有一束主光。** 太阳的位置、颜色和主光一致；小行星、星舰、平台都要有亮面和暗面。
3. **一套界面语言。** 颜色、线、字体、动效都来自同一份 token 文件。
4. **读字时画面让路。** 阅读状态下正文不倾斜、不被任何几何体穿过，文字对比度不低于 4.5:1。
5. **关键瞬间有导演。** 启航、跃迁、锁定、停靠四个瞬间，镜头、光、声音、界面在同一条时间轴上。
6. **不变卡。**
   - 集显在自动画质下的帧率不低于 v21.19。
   - 新增的 GPU 效果按画质档位开启。
   - 每批做完都按 [QA-V21-19](QA-V21-19.md) 的方法重测。

## 3. 界面方向：三选一

三种方向用同一张底图做了样张：锁定星舰的场景，去掉了现有界面和同心圆环。样张里光标靠近按钮或星舰时会被吸附，可以直接对比。

| | A 电影极简 | B 全息战术 | C 光学玻璃 |
|---|---|---|---|
| 参考 | 《遗落战境》《银翼杀手 2049》《降临》 | 《光环》《命运》《苍穹浩瀚》 | visionOS / Liquid Glass，现有的 OPTICAL LINK |
| 做法 | 细线、留白、等宽小字，只用一个暖色做强调；文字直接放在画面上，用渐变压暗 | 青色全息、扫描线、分段圆环、跳动读数、解码出字 | 磨砂玻璃、虹彩描边；高光和倾斜随指针变化，动效带回弹 |
| 长文可读性 | 最好 | 差，信息太密 | 好 |
| GPU 成本 | DOM / SVG，几乎为 0 | 低；大面积发光和扫描线有合成开销 | 最高：`backdrop-filter` 盖在每帧都在变的画布上，每帧都要重新模糊，集显上估计每块面板 1–3 ms |
| 风险 | 排版和节奏不准就会显得空 | 像游戏 UI，和作品集的气质有冲突 | 和场景里的 3D 玻璃重复，科幻感偏向消费电子 |

**推荐：A 为基础。**

- 锁定星舰的那一刻，借用 B 的锁定圈、读数滚动和解码出字。这一刻本身就是"战术"时刻。
- C 不做成界面风格，只用在场景里已有的 3D 玻璃面板上。

如果选 A，token 初稿如下：

- **颜色**
  - 正文 `#EEF1F5`，次要文字 60% 透明度，细线 `rgba(255,255,255,.22)`。
  - 唯一的强调色是暖琥珀 `#FFB46B`，只表示"当前 / 锁定 / 进行中"。
  - 不再使用品红。
- **字体**
  - 标题：Tem Narrative，字重 300。
  - 正文：Tem Interface。
  - 小标签和数据：新增一款等宽字体。现在只能落到系统的 Consolas / Bahnschrift，各机器显示不一致。
- **线与形**
  - 1 px 细线、8 px 角标、画面四角的安全框。
  - 不用粗边框，不用大圆角。
- **动效**
  - 入场 600–1000 ms，曲线 `cubic-bezier(.16,.84,.2,1)`，元素间隔 80–120 ms。
  - 退场 250 ms，不回弹。
  - 只动 `transform` 和 `opacity`。
- **声音**
  - 每个界面事件对应现有音效：`ui-appear`、`lock-on`、`scan-ping`、`dock`、`warp-whoosh`、`gate-chime`。

## 4. 分批方案

工作量按小、中、大估计。每项都写明了改哪里、多花多少 GPU、怎样算做完。

### 第 0 批：修瑕疵（与界面风格无关，工作量小）

**0-1 小行星改为岩石（#5、#13）**

- **改法**：
  - `immersive-spatial.js:138-144` 的碎石带和碎屑改用非金属岩石材质：metalness 0、roughness 0.85–1。
  - 每个实例随机明暗和色相（`setColorAt`）。
  - 几何改成 1 级细分的 20 面体，加一次性的顶点噪声位移，做 3–4 种形状变体。
  - 星图里的碎石（`immersive-starport-world.js:106-127`）已经是细分加位移的非金属岩石，可以直接复用。
- **成本**：顶点数增加，但仍是一次实例化绘制；GPU 基本不变。
- **验收**：到达、航行画面里的小行星都有受光面和阴影面，看不出重复形状。

**0-2 让圆环离开文字（#8、#11）**

- **改法**：
  - 把 `immersive-spatial.js:126-128` 的入口圆环挪到星舰左后方。
  - 或者在到达之后，把圆环淡到 15% 并缩小。
  - 文字面板加局部压暗。项目里已有的 `clipForeground()`（`immersive-world-surface.js:23-42`）可以在几何体挡到面板时给面板挖洞。
- **成本**：0。
- **验收**：到达、扫描、锁定、停靠四个画面里，没有任何几何体压在文字上。

**0-3 船坞灯（#6、#7）**

- **改法**：
  - 方盒灯改成小的点状发光体，按 1 Hz 的航行灯节奏闪烁。
  - 离相机太近时整体淡出。
  - 品红改成琥珀色或白色。
  - 航行镜头避开轨道环支架：要么调整轨道环的朝向，要么近距离时隐藏。
- **成本**：0。
- **验收**：完整浏览一轮，不再出现色块，也没有支架斜穿镜头。

**0-4 序章航门（#1）**

- **改法**：
  - `immersive-voyage-optical.js:10-16` 的两条细环不再用 HDR 纯白：改为低亮度的金属细环，配一串点状航行灯。
  - 调整航门的位置和角度，让弧线不穿过右上角的导航，也不压到标题。
- **成本**：0。
- **验收**：首屏只有标题和行星两个主体，右上角导航周围干净。

### 第 1 批：统一界面与交互（选定风格后做，工作量中）

**1-1 一份 token 文件替换层层覆盖**

- **改法**：
  - 新建 `immersive-hud.css`，放 token 和几个基础组件：小标签、细线、角标、按钮、面板、进度轨。
  - 按组件逐个替换 14 个样式表里的重复规则，同时删掉被覆盖的旧规则。
  - `immersive-refinement.css` 第 1 行的 `@import fonts.css` 改为在 HTML 里预加载首屏用到的字体子集，避免字体发现太晚。
- **验收**：`.archive-glass-panel` 的规则数从约 290 条降到 60 条以内；`!important` 只在必要处保留。

**1-2 读的时候正文不再倾斜（#10、#12、#16）**

- **改法**：
  - 进入阅读或停靠状态时，正文离开 3D 面，改到屏幕空间：右侧固定栏位，背后压暗。
  - 3D 面上只保留封面和框线。
  - 正文不在面板里滚动，改为整页展开或分段翻页。
  - 退出阅读时，正文再飞回 3D 面。
- **成本**：比现在每帧计算 `matrix3d` 还少。
- **验收**：作品舱和个人空间四个章节的正文都是水平的，没有被任何东西穿过。

**1-3 锁定框、引导线和读数**

- 星舰外面套四角括号，从外向里收拢。
- 一根细引导线连到信息栏。
- 距离读数从远到近滚动。
- 锁定瞬间借用 B 的锁定圈，并播放 `lock-on`。

**1-4 出字动效**

- 标题按行从遮罩里升起。
- 小标签的字距从宽收拢到正常。
- 数字滚动到位。
- 解码式出字只用在代号和数字上，不用在中文正文上。
- 每种效果只在进入新状态时播放一次。

**1-5 自定义光标**

- 平时是小准星。
- 靠近按钮或星舰时会被吸附，变成括号包住目标。
- 停在可停靠的星舰上时进入瞄准状态。
- 只在鼠标设备上显示；遵守"减少动态效果"设置。
- 现有代码里只有一个没被引用的准星（`immersive-cyber.js`），可以参考，但不直接复用。

**1-6 补齐声音**

- 现在 3D 悬停和点击画布都没有声音（`immersive-audio.js:200-233` 只处理 DOM 和旅程步骤）。
- 悬停星舰或星域时播放 `ui-hover`。
- 点击空白处发出探测脉冲时播放 `scan-ping`。

**1-7 星图整理（#17、#20）**

- **改法**：
  - 标签停止摆动，统一成一种样式。
  - 按屏幕位置做简单避让：重叠就沿连线方向推开。
  - 标题区加压暗，或者挪开浮空城。
- **验收**：四个标签同一尺寸、互不遮挡；标题下面没有亮物体。

**1-8 等宽字体**

- 加一款等宽字体的拉丁字母加数字子集，约 20–30 KB。
- 替换样式里写死的 Consolas，以及 3D 画布标签用的系统字体。

### 第 2 批：光与镜头（按档位开启，工作量中）

**2-1 太阳归位（#3）**

- 太阳贴片放到真实主光方向的无穷远处，改为暖色。
- 遮挡判断从"只认解析球"改为读深度图。场景深度已经在 `atmosphere.particleUniforms.uSceneDepth` 里。

**2-2 镜头光学**

- 在 `immersive-film.js:33-36` 的基础上做三层：
  - 星芒；
  - 横向拉丝；
  - 3 个看得见的鬼影。
- 档位分配：`light` 档只开横纹，`balanced` 档加星芒，`cinematic` 档全开。

**2-3 体积光**

- 太阳在画面内、又被星云或行星部分挡住时，做 1/4 分辨率的径向模糊。
- 只在 `cinematic` 档开启。

**2-4 分场景调色**

- 在胶片通道里加 lift / gamma / gain、饱和度和色温，按旅程步骤和星域插值。
  - 启航：冷蓝紫。
  - 空间站：青灰。
  - 星图：紫粉。
  - 到达：暖金。
  - 作品舱：从封面图取主色。
- 胶片通道已经在做分离色调，加这些几乎没有成本。

**2-5 阅读时的景深**

- 只在 `cinematic` 档、只在阅读或停靠状态下，让背景轻微虚化。
- 用半分辨率做。

**2-6 独显放开分辨率**

- `cinematic` 档的像素上限从 1.8 MP 改为按屏幕计算（1440p 约 3.7 MP）。
- 同时补上后处理抗锯齿。这对应性能方案的 B3，本轮只做了 MSAA 分档。
- 解决细线和圆环发软、闪烁的问题。

**2-7 镜头运动**

- 所有相机移动改用临界阻尼弹簧，到位时有不超过 2% 的过冲。
- 待机时加极慢的呼吸漂移，以及 ±0.6° 的鼠标视差。

**2-8 星图地面反光（#19）**

- 先查清来源，再降低那一处的镜面强度。

### 第 3 批：跃迁与关键瞬间（工作量中）

**3-1 星域跃迁三段式（#4）**

序章里的扭曲、色散、拖影已经写好（`immersive-film.js:19-29`），只要让星域航行也能驱动 `uWarp`：

1. **蓄力，0.4 s**
   - 视场角收紧 4°，星点向中心聚拢，引擎声升调。
2. **跃迁**
   - 星光沿速度方向拉长，颜色从白到青到紫色散。
   - 视场角冲到 +20°，接上序章的扭曲和拖影，四角压暗。
   - 航行线从 1 像素线改为有宽度、有 HDR 亮度的光带，这样能触发泛光。
3. **出跃迁，0.15 s**
   - 白闪，加一道扩散的冲击波环，视场角回弹，播放 `gate-chime`。

额外的 GPU 开销只在跃迁的 2–3 秒内出现。

**3-2 锁定**

- 扫描波从星舰向外扩散，锁定框随之收拢。
- `lock-on` 音效和读数滚动对齐到同一帧。

**3-3 停靠**

## 5. 性能预算

以下成本是估计值，实施后都要实测。

| 效果 | light | balanced | cinematic | 估计成本（Iris Xe / RTX 3070） |
|---|---|---|---|---|
| 新界面（DOM / SVG） | 开 | 开 | 开 | 约 0 |
| 第 0 批全部 | 开 | 开 | 开 | 约 0 |
| 分场景调色 | 开 | 开 | 开 | < 0.1 ms |
| 镜头光学 | 横纹 | + 星芒 | + 鬼影 | < 0.2 ms |
| 体积光 | 关 | 关 | 开 | 约 0.8 ms / < 0.2 ms |
| 阅读景深 | 关 | 关 | 开（仅阅读） | 约 1 ms / 约 0.2 ms |
| 跃迁效果 | 开 | 开 | 开 | 只在跃迁的 2–3 s 内 |
| 放开分辨率 + SMAA | 关 | 关 | 独显 | 由独显承担 |
| 行星着色器重写 | — | — | — | 与现在相当 |

几条约束：

- 集显在自动画质下已经停在分辨率下限，没有余量。性能方案第 3 批（星云隔帧更新、地面降本、展具合批）省出来的时间，先用来提高分辨率，再用来加效果。
- 不要在 3D 画布上大面积使用 `backdrop-filter`。
- 动画只改 `transform` 和 `opacity`。

## 6. 建议顺序

**0 → 1 → 3 → 2 → 4 → 5。**

- 第 0 批修的是一眼就能看到的瑕疵。
- 第 1 批是成本最低、观感提升最大的一步。
- 第 3 批做的是"哇"的瞬间。
- 第 2 批让画面更丰富，但依赖性能方案第 3 批腾出预算。
- 第 4 批工作量最大，可以挑着做。
