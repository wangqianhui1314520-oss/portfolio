## 性能证据与未完成项

本轮桌面实测出现严重波动：早期完整场景约 5–11 fps / GPU 60–109 ms；按需加载后欢迎页采到约 21 fps / GPU 19.06 ms，阅读约 23 fps，进入星图时仍采到 8 fps / GPU 51.50 ms。上述为本机当前负载下的样本，不能视为稳定 60 fps 已达成，也不能仅凭这些不同状态断言所有差异都由某个改动导致。

当时 NVIDIA 设备读数为 RTX 3070 Laptop、97% 利用率、显存约 7,461MB；Unity 与 Codex 均有图形占用，未结束用户的其他应用。375×812 场景采到约 54 fps / GPU 3.20 ms。保持完整画质，未以降低质量偏好掩盖性能问题。

仍需继续处理：桌面在实际负载下的帧率、星云更细的明暗尺度、平台和阅读界面的遮挡关系、T 端面白块及右侧地面强高光。离线渲染中的改善不能当作所有实时高光已消除，当前效果也没有完全达到概念图。
