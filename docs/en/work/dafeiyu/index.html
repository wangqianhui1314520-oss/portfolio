Project overview

An AI companion that runs on a personal computer. QQ conversations connect persona, long-term memory, knowledge, proactive check-ins, and scheduled reminders into an ongoing relationship, with image understanding, voice, and multimedia interactions.

Project details & context
Runtime
Resident local services · QQ direct messages / group chats
Message bridge
Node.js · DSH plugins · OneBot v11
Data & services
Local memory and knowledge; models and voice may use external services
DESIGN & EVIDENCE

Give the next conversation a place to continue

System-design illustration, not a cross-day conversation replay. The image is a crop from an earlier interface.

  1. 01

    Organize in layers

    Persona, long-term memory, and knowledge are managed separately, giving retained information a clear home.

  2. 02

    Reconnect context

    Everyday messages pass through a local bridge to memory and tools, supporting continuity across conversations.

  3. 03

    Respect the rhythm

    Proactive contact considers time, availability, and unanswered messages. Reminders run separately and services support recovery.

How to verify

Start with the historical dashboard to understand how messages, memory, and tasks are organized. Then examine three design questions: how memory is inspected and deleted, when contact is initiated, and how services recover.
