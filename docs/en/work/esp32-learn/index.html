Project overview

An interactive ESP32 learning platform for IoT and electronics learners. A browser-based board, Wokwi simulation, wiring diagrams, and a virtual lab connect first LEDs to AI-enabled experiments.

  • 13 modules / 47 chapters / approximately 10.6 hours
  • Wokwi simulation and interactive wiring
  • Virtual lab with 24 components
  • Self-tests, completion certificates, and locally saved progress
  • Static Vue 3 implementation

DESIGN APPROACH

From a question to an experience

Let learners operate and understand ESP32 experiments without a physical development board.
