Project overview

A side-scrolling squad action-puzzle game for the browser that turns talking to AI into play. As DeepSeek, a whale-tailed heroine, you lead Grok, Claude, and GLM into an undersea server vault: dash through barriers and haul data yourself, and give your crew orders. A default order saves resources but can reach more than you meant; a precise qualifier keeps control but is limited. Five chapters end with a sixty-second evacuation.

DESIGN APPROACH

From a question to an experience

The hardest part of working with AI is often saying exactly what you mean. Can a game let players feel that firsthand — a vague order carried out to the letter and too far, a precise one that costs something?

A game-track entry for WaytoAGI’s 1024 Coding Weekend: a playable version built solo within the two-day, 1,024-minute event and released online, then refined afterward. It is also a WorkBuddy 1024 Programmer’s Day project, with a complete development log. The idea came from an October 2026 security report in which an attacker had several AI models split the work, then left their session logs in an open directory. The game borrows that irony — AI teamwork undone by its own exposure — as a fictional undersea comedy. Its institutions, maps, and events are invented; it contains no real targets, methods, or tools.

Turn prompting into tactics

Each crewmate has a dependable default: Grok smashes through a run of barriers, Claude lures several guards with an outrageous résumé, and GLM scans a wide area. A default order costs only AI tokens but can reach more than intended; a qualifier narrows it to one spot or one guard, but each chapter allows only a few. Before confirming, a free “echo preview” shows what will be affected, likely alarms, and what it means for the way back.

Make the way back part of the level

The pack holds three pieces of data; once it is full, you return to the whale boat to deliver. Opened passages and lured guards stay that way for the return trip. Chapter four reveals that the mothership has been broadcasting the crew’s log all along: switch it off and regroup. In chapter five, gather all three crewmates at a far beacon, confirm the load, and get everyone out within sixty seconds.

Build it in two days, then make it dependable

Vanilla JavaScript and layered Canvas 2D keep rules, world simulation, rendering, and interface separate, with no runtime dependencies and static hosting. Working with Codex and WorkBuddy, I kept 32 scripted regression checks and browser checks running; after the event, fixes covered stuck input and blurry phone rendering, and a WebP migration cut the deployed build from 114 MB to 26 MB.
